# ⚽ Football AI Assistant

## 📌 Обща информация

Football AI Assistant е модулна информационна система за управление и анализ на футболни данни.  
Проектът комбинира релационна база данни, Python backend логика, AI модул и чатбот функционалност.

Системата позволява структурирано съхранение, обработка и анализ на информация за:

- футболни клубове
- играчи
- мачове
- лиги
- голове
- картони
- трансфери

Проектът е разработен като основа за интелигентен футболен асистент, който в бъдеще може да предлага статистики, прогнози и автоматизирани отговори.

---

# 🎯 Цел на проекта

Основната цел е създаване на цялостна backend система, която:

- управлява футболна информация
- поддържа релационна база данни с връзки
- осигурява CRUD операции
- позволява статистически анализ
- интегрира AI логика
- подготвя REST API за бъдещ frontend

# 🗄️ Използвана база данни

База данни: **SQLite**

## Причини за избора:

- не изисква сървър
- лека и бърза
- интегрира се директно с Python
- подходяща за учебен проект
- лесна за пренос (един файл)

Файл на базата: `database.db`

---

# 🏗️ Структура на базата данни

## Основни таблици:

- clubs
- players
- matches
- leagues
- league_teams
- goals
- cards
- transfers

## Връзки:

- Един клуб има много играчи
- Един мач принадлежи към лига
- Един мач има домакин и гост
- Един мач има много голове
- Един мач има много картони
- Играч може да има множество трансфери

Всички връзки са реализирани чрез FOREIGN KEY ограничения.
